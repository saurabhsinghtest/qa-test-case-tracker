# QA Test Case Tracker

A lightweight, browser-based app for managing manual QA test cases and tracking their execution status (Passed, Failed, Blocked, Not Run). Data is stored in the browser's localStorage.

> Status: **Step 1 — Project Setup complete.** Features are in development. See [PLAN.md](PLAN.md) for the full plan.

## Tech Stack
React · TypeScript · Vite · CSS · Vitest + React Testing Library · Vercel

## Getting Started
```bash
npm install        # install dependencies
npm run dev        # start dev server at http://localhost:5173
```

## Scripts
| Command | Description |
|---|---|
| `npm run dev` | Start the development server |
| `npm run build` | Type-check and build for production into `dist/` |
| `npm run preview` | Preview the production build locally |
| `npm test` | Run all tests once |
| `npm run test:watch` | Run tests in watch mode |
| `npm run test:coverage` | Run tests with a coverage report |
| `npm run lint` | Lint the code with Oxlint |
